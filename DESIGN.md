# KeyTrail / 钥迹

Mode: Operate. A Windows desktop instrument for long-running work, not a landing page.

Graphite masthead, warm-white work surface, restrained copper controls. Flat aligned rows, not a collection of cards. Clear running/paused indicator and an oversized, tabular actual throughput value establish hierarchy; zero/paused values remain truthful. Range and payout settings retain their separate pages. No decorative charts, gradient, slogan or extra explanatory captions. Native UI typography for controls; monospace for keys and measured values. Persistent keyboard focus, accessible foregrounds, reduced-motion support.

Only presentation, display branding, icon and version change in v1.2.1. Internal app identity, default legacy data-directory names, engine, monitor, checkpoint and payout logic stay unchanged.

Review: 1440, 1024, 820 and 600 px widths; all five languages; range change/restore on a separate copied test profile; payout authorization left off.

Reference read: https://github.com/pbakaus/impeccable — Operate, distill and craft-floor. Product-specific interpretation, not a copy of that website or a claim of running its detector.

v1.3.0: no additional Windows system-title row. Embedded frameless shell, native window controls integrated into the existing graphite masthead and a dedicated blank drag region. No prefilled receiving wallet in source or build.

Scroll tracks are hidden in both the page and activity list. Wheel, touchpad and keyboard scrolling stay enabled; content is not clipped to fake an unscrollable canvas.
