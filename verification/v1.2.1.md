## Prior integration checks retained, not a new mainnet claim

The unchanged payout module previously passed Bitcoin Core 32.1 **regtest-only** integration cases for Taproot, SegWit, legacy and an accepted transaction with its response lost. Each case checked signing, node acceptance, mined confirmation, exact destination amount, only one broadcast, restored receipt and grant reset. Only valueless regtest coins were used. The integration suite is included as `scripts/check-regtest.py`.

This release's checks do not prove that every Windows machine or GPU works, that a public bounty is still unspent, or that a mainnet payout will win a competing spend. The application performs its own public status monitoring while running.
