# KeyTrail v1.3.0 verification

Privacy and native-window update. The default receiving address is empty. Addresses are loaded solely from the installation's local configuration; the release package never includes local user state. New installs require a valid mainnet address before search or automatic payout authorization. Existing valid configs keep their addresses and checkpoints locally.

43 unit tests cover default privacy, rejection of empty payout authorization, range/checkpoint compatibility, payout/receipt protections, narrow window controls and restriction to a local UI URL. Payout tests use explicitly derived public test fixtures and fictional outputs, not a personal wallet.

The frameless pywebview/WebView2 window replaces the separate OS title row. Its controls minimize, maximize/restore and hide the window; the tray retains backend access. The UI process watches backend exit. Test/debug access is used only on isolated QA profiles and is not enabled in normal application startup.

Local acceptance checks and packaged diagnostics are run before this release is published. No formal #71 search or real BTC transfer is started for UI verification. Previous regtest-only payout checks are retained for the unchanged transaction signing and receipt paths; they are not proof of winning a mainnet race.

Rendered native QA passed in five languages and at four viewport widths (1440/1024/820/600). Win32 caption flags were absent; custom minimize/maximize/restore/hide/reopen and header drag were exercised. Page and activity scroll tracks are hidden without disabling scrolling; overflowed content remained reachable.

Final packaged EXE passed CUDA solved-#20 and offline-payout diagnostics. Embedded application code and UI/resources were scanned against the local private receiving address without logging that address; none contained it. Installation preserved all saved progress rows, active plan, locally configured receiving address and language. Production WinForms window caption bits were checked absent; automatic submission remained unarmed.
